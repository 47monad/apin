# Zaal [ARCHIVED]

[![Status: Archived](https://img.shields.io/badge/Status-Archived-inactive)]()

> Named after Zāl (زال), the legendary Persian hero and father of Rostam in Ferdowsi's Shahnameh.

This repository has been **absorbed into [apin](https://github.com/47monad/apin)** as the
[`apin/manifest`](https://github.com/47monad/apin/tree/main/manifest) package (apin#36). All
configuration loading — the CUE schema, section structs, environment overlay, and the
loader — now lives in the apin repository and evolves in lockstep with the initrs that
consume it.

- **Code & docs:** https://github.com/47monad/apin/tree/main/manifest
- **User-facing entry point:** [`apin.LoadConfig`](https://github.com/47monad/apin) / `apin.MustLoadConfig`
- **Open issues:** carried over to the [apin issue tracker](https://github.com/47monad/apin/issues)

This repo is archived and read-only. Thank you to everyone who tried it out while it was
under development.
